# 🛡️ CyberSage: Agentic AI Security Scanner

An automated security scanning tool combining SAST (Semgrep), custom DAST checks, and RAG-based vulnerability remediation guidance. Built specifically for Streamlit Community Cloud with zero-crash fallbacks.

---

## ⚡ Quickstart

### 1. Local Setup
```bash
git clone [https://github.com/your-username/cyber-agent-scanner.git](https://github.com/your-username/cyber-agent-scanner.git)
cd cyber-agent-scanner
pip install -r requirements.txt
streamlit run app.py
